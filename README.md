# meho-analytics
## Prerequisite
Installed latest AWS CLI from https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-install.html

`aws --version` should show the version

## Run
`python meho_dynamo_content_parser.py` 
should generate all_content.json in current folder

`python meho_dynamo_user_parser.py`
should generate all_user.json in current folder
